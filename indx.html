الذكاء الاصطناعي التوليدي (Generative AI) يتميز بقابلية ابتكار وإنتاج بيانات ومحتويات جديدة تماماً مستمدة من الأنماط التي تعلمها أثناء التدريب.
سؤال 2

الإجابة الصحيحة هي (ج): بدء وتفعيل سير العمل (Workflow) فور وقوع حدث معين مثل (Webhook أو جدولة زمنية).
عقدة الـ Trigger هي بمثابة شرارة البدء لأي أتمتة في n8n، حيث تستمع للأحداث الخارجية أو التوقيت وتُطلق تنفيذ المسار.
سؤال 3
تتكون الهيكلة الأساسية لوكيل الذكاء الاصطناعي (AI Agent) التفاعلي والمستقل في n8n من ثلاثة أركان رئيسية هي:
الإجابة النموذجية والتوضيح:
الإجابة الصحيحة هي (ب): النموذج اللغوي (Model)، الذاكرة (Memory)، والأدوات (Tools).
يتكون وكيل الذكاء الاصطناعي (AI Agent) من: النموذج اللغوي للعقل والمحاكمة، الذاكرة لحفظ السياق، والأدوات للتنفيذ والاستعلام الخارجي.
سؤال 4
ما أهمية الذاكرة (Memory Node) بالنسبة لوكيل الذكاء الاصطناعي في n8n؟
الإجابة النموذجية والتوضيح:
الإجابة الصحيحة هي (ب): تسمح للوكيل بتذكر سياق المحادثات السابقة واستدعائها لإتمام الحوار بشكل منطقي.
بدون الذاكرة، يتعامل الذكاء الاصطناعي مع كل رسالة كأنها الأولى، لكن الذاكرة تمنحه سياق المحادثة الممتدة.
سؤال 5
ما هو دور الأدوات (Tools) المربوطة بوكيل الذكاء الاصطناعي؟
الإجابة النموذجية والتوضيح:
الإجابة الصحيحة هي (أ): تمكّن الوكيل من التفاعل مع الأنظمة الخارجية واستدعاء APIs أو البحث أو كتابة بيانات.
الأدوات (Tools) هي الأذرع التي تمكن الوكيل من تنفيذ أفعال في العالم الخارجي مثل الاستعلام، إرسال رسائل، أو البحث.
سؤال 6
ماذا يقصد بمفهوم 'System Prompt' (تعليمات النظام) عند تهيئة الذكاء الاصطناعي؟
الإجابة النموذجية والتوضيح:
الإجابة الصحيحة هي (ب): التوجيهات والتعليمات الأساسية التي تحدد شخصية الوكيل، دوره، حدوده، وطريقة إجابته.
تعليمات النظام (System Prompt) تضبط سلوك الوكيل وقواعد الأمان والنبرة القياسية التي يجب الإلتزام بها أثناء الرد.
سؤال 7
ما هي التقنية التي ترمز إلى (RAG - Retrieval-Augmented Generation)؟
الإجابة النموذجية والتوضيح:
الإجابة الصحيحة هي (ب): إستراتيجية تعزز إجابات النموذج اللغوي باسترجاع دقيق للمعلومات من قواعد معرفية خارجية مخصصة.
تقنية RAG تدمج بين استرجاع البيانات المخصصة (من ملفات أو قواعد بيانات) وتوليد النصوص عبر الذكاء الاصطناعي لضمان إجابات دقيقة ومحدثة.
سؤال 8
ما هي وظيفة الـ Webhook Trigger في سير عمل n8n؟
الإجابة النموذجية والتوضيح:
الإجابة الصحيحة هي (ب): استقبال طلبات HTTP من تطبيقات خارجية لحظياً وتفعيل سير العمل فوراً.
الـ Webhook يسمح لأي تطبيق خارجي بتفعيل الـ Workflow في n8n فور وقوع حدث عن طريق إرسال HTTP Request.
سؤال 9

الإجابة الصحيحة هي (أ): تُستخدم لتوجيه تدفق البيانات والقرارات لمسارات مختلفة بناءً على شروط أو نتائج محددة.
عقد Decision (IF / Switch) تسمح بعمل منطق التفرع الشجري وتوجيه التنفيذ حسب البيانات المخرجة.
سؤال 10
ما المقصود بـ 'Vector Embeddings' في سياق الذكاء الاصطناعي وقواعد البيانات المتجهة؟
الإجابة النموذجية والتوضيح:
الإجابة الصحيحة هي (ب): تمثيل رقمي دلالي للنصوص والمعلومات في شكل متجهات رياضية لمقارنة التشابه المعنوي.
الـ Embeddings تحول الكلمات والنصوص إلى متجهات عددية تعبر عن المعنى، مما يسمح بالبحث الدلالي (Semantic Search).
سؤال 11

الإجابة النموذجية والتوضيح:
الإجابة الصحيحة هي (أ): HTTP Request تستدعي خدمات APIs خارجية مباشرة، بينما Code Node تُنفذ أكواد مخصصة (JavaScript/Python) لمعالجة البيانات.
عقدة HTTP Request تتواصل مع واجهات برمجة التطبيقات الـ APIs، بينما Code Node تتيح كتابة كود برمجي مخصص للتحكم الكامل بالبيانات.
سؤال 12

الإجابة النموذجية والتوضيح:
الإجابة الصحيحة هي (ب): درجة العشوائية والإبداع في إجابات النموذج (قيمة منخفضة = إجابة محددة ودقيقة، قيمة عالية = إبداع وتنوع).
معامل الـ Temperature يحدد مستوى الإبداع في الرد؛ فالقيم المنخفضة (مثل 0.2) تعطي إجابات صارمة ودقيقة، والقيم المرتفعة تزوج بالإبداع.

الإجابة الصحيحة هي (ب): Postgres Chat Memory / External Database Memory.
استخدام ذاكرة مربطة بقاعدة بيانات مثل Postgres يضمن بقاء سجل المحادثات حتى بعد إعادة تشغيل الخوادم.
سؤال 14

أسلوب Few-Shot يعتمد على إعطاء النموذج أمثلة محلولة مسبقاً داخل الأمر ليحاكي نفس التنسيق والسلوك.
سؤال 15

عقدة Error Trigger تلتقط الاستثناءات والفشل في أي عقدة، مما يسمح بإرسال إشعارات طوارئ أو تنفيذ خطط إخفاق بديلة.

الـ Tokens هي الوحدات النصية المقطعة التي يقرأها النموذج ويتعامل معها (تقريباً 100 توكن تشكل حوالي 75 كلمة إنجليزية).
سؤال 17

وكيل الذكاء الاصطناعي يستطيع الاستعلام من قاعدة البيانات وأدلة الصيانة المرفقة لتقديم تشخيص سريع وتوجيه مهندسي الصيانة.
سؤال 18

الإجابة النموذجية والتوضيح:
الإجابة الصحيحة هي (ب): يستخدم حلقة التفكير والتخطيط (ReAct Loop) لتقسيم المشكلة واختيار الأدوات المناسبة بالترتيب.
نمط ReAct (Reasoning + Acting) يسمح للوكيل بالتفكير خطوة بخطوة، واختيار الأداة، وتقييم النتيجة، ثم الانتقال للخطوة التالية.

عقدة Edit Fields تُستخدم لإعادة تشكيل هيكل البيانات (JSON) وتجهيز الحقول قبل تمريرها للعقد التالية.
سؤال 20

قواعد البيانات المتجهة مثل Pinecone و Qdrant مخصصة لتخزين المتجهات واسترجاع المعلومات المتشابهة دلالياً بسرعة عالية.

الإجابة الصحيحة هي (ب): قد تفشل عملية الاستدعاء (Tool Execution Error)، لذا يجب توضيح وصف الشروط بدقة في الـ System Prompt والأداة.
يجب تحديد صيغ ووصف أدوات AI Agent بدقة لتفادي الأخطاء أثناء قيام الوكيل بتمرير المعاملات (Parameters).
سؤال 22

الإجابة النموذجية والتوضيح:
الإجابة الصحيحة هي (أ): إعادة تدريب نموذج محدد مسبقاً على مجموعة بيانات مخصصة ليتخصص في مجال محدد بدرجة عالية.
التعديل الدقيق (Fine-Tuning) يدرب النموذج العام على أسلوب أو بيانات متخصصة جداً لرفع كفاءته في مهمة محددة.
سؤال 23

الإجابة النموذجية والتوضيح:
الإجابة الصحيحة هي (أ): أنها صيغة خفيفة وموحدة وسهلة القراءة من البرامج والذكاء الاصطناعي لتنظيم البيانات المعقدة.
JSON هي الصيغة القياسية لتبادل البيانات وتتيح تنظيم البيانات في شكل أزواج من المفاتيح والقيم (Key-Value).

الإجابة الصحيحة هي (ب): إنتاج الذكاء الاصطناعي لمعلومات غير صحيحة أو مختلقة بثقة تامة.
الهلوسة تعني إعطاء النموذج إجابات خاطئة أو مخترعة يبدو ظاهرياً أنها صحيحة، وتساعد تقنية RAG في الحد من هذه المشكلة.

الأتمتة الذكية تجمع بين قدرة الذكاء الاصطناعي على التحليل وسرعة تنفيذ الـ Workflows في اختصار الوقت وتقليل الأخطاء.
